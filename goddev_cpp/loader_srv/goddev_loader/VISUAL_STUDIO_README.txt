Open loader_goddev.sln in Visual Studio.

What to install:
- .NET desktop development
- .NET 8 SDK

How to run:
1. Right click the project.
2. Set as Startup Project.
3. Press F5.

Where to edit:
- MainWindow.xaml          UI and layout
- MainWindow.xaml.cs       button logic and animations
- ApiService.cs            API URL and software path
- Models.cs                response models

Important:
- API URL is in ApiService.cs
- Software path is in ApiService.cs
- Rounded compact window is built in XAML
- The app uses a borderless WPF window
