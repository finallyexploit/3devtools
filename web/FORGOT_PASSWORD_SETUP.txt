Почта:
Сейчас используется стандартная PHP mail().
На хостинге должна быть настроена отправка почты.

Можно задать переменные окружения:
- GODDEV_MAIL_FROM
- GODDEV_MAIL_NAME
- GODDEV_MAIL_REPLY_TO
- GODDEV_SITE_URL

Пример:
GODDEV_MAIL_FROM=no-reply@soulware.space
GODDEV_MAIL_NAME=GOD DEV
GODDEV_MAIL_REPLY_TO=support@soulware.space
GODDEV_SITE_URL=https://soulware.space


If forgot password still fails, check forgot_password.log next to api.php.

SMTP для этого хоста:
- Открой mail_config.php
- Впиши пароль ящика в password
- host: mail.soulware.goddevhost.com
- port: 465
- secure: ssl
- username: goddev@soulware.goddevhost.com
